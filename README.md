# СтройБот 🏗

Telegram-бот и Mini App (приложение внутри Telegram) для ремонта и стройки: дизайн комнаты по фото,
калькулятор материалов, смета, проверка работы бригады, консультант, коммерческие предложения,
учёт объектов (расходы, выплаты, этапы с напоминаниями), фотоотчёты в PDF, голосовые сообщения,
реферальная программа. Оплата — Telegram Stars.

## Что нужно заранее
1. **Токен бота** — написать @BotFather → `/newbot` → скопировать токен.
2. **Ключ kie.ai** — зарегистрироваться на kie.ai, пополнить баланс (для тестов хватит ~$5–10),
   взять ключ на странице API Key.
3. **Свой Telegram ID** — написать @userinfobot.
4. **Python 3.11+** на компьютере или сервере.

## Запуск
```bash
cd stroybot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
# откройте .env и впишите BOT_TOKEN, KIE_API_KEY, ADMIN_IDS
python -m bot
```
Откройте бота в Telegram и нажмите /start. Бот работает и без Mini App — его можно включить позже.

## Mini App (приложение внутри Telegram)
В приложении есть всё, что умеет бот:
- объекты (расходы, этапы, бюджет);
- дизайн по фото со шторкой «до/после», смета, проверка работы, консультант, КП;
- фотоотчёт в PDF (приходит в чат);
- замер по скану из LiDAR-приложений («Рулетка», Polycam, 3d Scanner App);
- сканы комнат из приложения СтройСкан для iPhone с лидаром (папка `ios`, инструкция в `ios/README.md`);
- строительный уровень на датчиках телефона и камера с линией горизонта;
- калькулятор;
- профиль с пополнением звёздами и приглашениями.

Telegram открывает Mini App только по адресу
с **HTTPS**, поэтому нужен сервер с доменом:
1. Купите домен (или поддомен) и направьте его на сервер.
2. Поставьте nginx и сертификат: пример в `deploy/nginx.conf`, затем `sudo certbot --nginx -d ваш.домен`.
3. В `.env` впишите `WEBAPP_URL=https://ваш.домен` и перезапустите бота.

После этого в меню бота появится кнопка «📱 Открыть приложение», а слева от поля ввода — кнопка «Приложение».
Для проверки без сервера подойдёт временный HTTPS-туннель (например, `cloudflared tunnel --url http://localhost:8080`).

## Команды
Для всех: `/start`, `/menu`, `/objects` — мои объекты, `/report` — фотоотчёт, `/scanner` — подключить LiDAR-сканер на iPhone, `/paysupport` — помощь
с оплатой (обязательна по правилам Telegram), `/terms` — условия, `/help`.

Для админа:
- `/stats` — пользователи, звёзды, генерации, объекты, приглашённые
- `/give <user_id> <кредиты>` — начислить кредиты (например, себе для тестов)
- `/refund <код платежа>` — вернуть звёзды и списать кредиты этой покупки (код видно в `/paysupport`)
- `/reply <user_id> <текст>` — ответить на обращение из `/paysupport`

## Где что менять
- Цены, пакеты, бонус за друга, лимиты — `bot/config.py`
- Промпты, стили дизайна — `bot/prompts.py`
- Тексты кнопок — `bot/keyboards.py`
- Экраны Mini App — `bot/webapp/index.html`, его API — `bot/web.py` и `bot/web_tools.py`

## Проверка
`python -m pytest -q` — 33 теста: калькуляторы, база, оплата и возвраты, рефералка, учёт объектов,
PDF, защита Mini App и сквозные сценарии бота (без настоящего Telegram и kie.ai).

## Продолжить в Claude Code
Откройте папку `stroybot` в Claude Code — контекст проекта в `CLAUDE.md`, план в `docs/TZ.md`,
правила проекта в `.specify/memory/constitution.md`. Новые функции удобно делать через Spec Kit:
`/speckit-specify` → `/speckit-plan` → `/speckit-tasks` → `/speckit-implement`.

## Сервер
VPS с Ubuntu (Timeweb, Beget, Selectel — от 300 ₽/мес). Скопируйте проект в `/opt/stroybot`,
выполните шаги «Запуск», затем включите автозапуск: `deploy/stroybot.service` (инструкция внутри файла).
