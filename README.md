# СтройБот 🏗

Telegram-бот и Mini App (приложение внутри Telegram) для ремонта и стройки: дизайн комнаты по фото,
калькулятор материалов, смета, проверка работы бригады, консультант, коммерческие предложения,
учёт объектов (расходы, выплаты, этапы с напоминаниями), фотоотчёты в PDF, голосовые сообщения,
реферальная программа. Оплата — Telegram Stars.

## Что нужно заранее
1. **Токен бота** — написать @BotFather → `/newbot` → скопировать токен.
2. **Ключ kie.ai** — зарегистрироваться на kie.ai, пополнить баланс (для тестов хватит ~$5–10),
   взять ключ на странице API Key.
3. **Свой Telegram ID** — написать @userinfobot.
4. **Python 3.11+** на компьютере или сервере.

## Запуск на Windows одним щелчком

Дважды щёлкните `start-bot.bat`: он всё поставит, спросит токен и ключ, откроет бесплатный https-адрес через Cloudflare и запустит бота. Подробно: [windows/README.md](windows/README.md). Проверить ключи отдельно: `python -m bot.check`.

## Запуск вручную
```bash
cd stroybot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
# откройте .env и впишите BOT_TOKEN, KIE_API_KEY, ADMIN_IDS
python -m bot
```
Откройте бота в Telegram и нажмите /start. Бот работает и без Mini App — его можно включить позже.

## Mini App (приложение внутри Telegram)
В приложении есть всё, что умеет бот:
- объекты (расходы, этапы, бюджет);
- дизайн по фото со шторкой «до/после», смета, проверка работы, консультант, КП;
- фотоотчёт в PDF (приходит в чат);
- замер по скану из LiDAR-приложений («Рулетка», Polycam, 3d Scanner App);
- сканы комнат из приложения СтройСкан для iPhone с лидаром (папка `ios`, инструкция в `ios/README.md`);
- строительный уровень на датчиках телефона и камера с линией горизонта;
- калькулятор;
- профиль с пополнением звёздами и приглашениями.

Telegram открывает Mini App только по адресу
с **HTTPS**, поэтому нужен сервер с доменом:
1. Купите домен (или поддомен) и направьте его на сервер.
2. Поставьте nginx и сертификат: пример в `deploy/nginx.conf`, затем `sudo certbot --nginx -d ваш.домен`.
3. В `.env` впишите `WEBAPP_URL=https://ваш.домен` и перезапустите бота.

После этого в меню бота появится кнопка «📱 Открыть приложение», а слева от поля ввода — кнопка «Приложение».
Для проверки без сервера подойдёт временный HTTPS-туннель (например, `cloudflared tunnel --url http://localhost:8080`).

## Ремонт по 3D-скану

Скан из приложения СтройСкан приходит в бот вместе с мебелью, фото комнаты и точными размерами (стены без окон и дверей, плинтус, откосы, где какая стена и где на ней окна и двери). Если приложение видит, что часть комнаты снята плохо, в сообщении будет «⚠️ Нужно доснять» — что именно пересканировать. Бот сразу считает материалы по этим размерам (`calc.scan_materials`) и даёт кнопки:
- «🎨 Ремонт на картинке» — фото с iPhone (или своё фото комнаты, присланное в чат) превращается в готовый ремонт по точным размерам; если фото нет, картинка рисуется по размерам через `T2I_MODEL`. Все картинки просим делать как настоящее фото, без «компьютерного» вида;
- «🧊 Ремонт в 3D» (когда включён Mini App) — комнату можно крутить и менять обои, пол, люстру, шторы и мебель; «Как в жизни» превращает снимок 3D-модели в фото с теми же размерами и расстановкой (стоит как картинка ремонта, 2 кредита);
- «🛋 Мебель по размерам» — сколько места у каждой вещи (с проходом 70 см и не закрывая двери) и что встанет на свободные стены; кнопки открывают поиск на Яндекс Маркете, Ozon, Wildberries и Divan.ru с размером в запросе (бесплатно);
- «📋 Смета по скану» — учитывает отделку и мебель, выбранные в 3D.

Файл скана «Комната.stroyscan.json» из приложения можно просто прислать в чат — в любой момент или в «Дизайне по фото»: бот сохранит его как обычный скан, вместе с ремонтом, собранным в 3D (картинка, мебель и смета его учтут). В «Дизайне по фото» бот сам предлагает последние сканы.

API для приложения (вход по токену) и Mini App (подпись Telegram):
- `POST /scan/rooms` — скан (формат v2: `wall_lines`, окна и двери с `wall`/`offset`/`bottom`, `quality`; старый формат тоже принимается);
- `GET /api/scans/{id}` — скан для 3D; `GET|PUT /api/scans/{id}/look`, `GET /scan/look?scan_id=`, `PUT /scan/look` — ремонт, собранный в 3D;
- `POST /api/scans/{id}/render`, `POST /scan/render` — фото «как в жизни» по снимку 3D; `POST /scan/design` — ремонт на фото;
- `GET /api/scans/{id}/furniture`, `POST /scan/furniture` — мебель по размерам со ссылками.

Код: `bot/scan_ai.py` (картинки и смета), `bot/web_scan.py` (API), `bot/handlers/scans.py` (кнопки и файл в чате), `bot/room.py` (геометрия комнаты), `bot/look.py` (ремонт из 3D), `bot/furniture.py` (мебель по размерам).

## Портфолио «до/после»

`/portfolio`, кнопка в меню прораба и экран «Портфолио» в Mini App. Прораб добавляет фото до и после, бот делает коллаж 1080×1080 с подписью бригады, пост для Telegram и VK (ИИ смотрит на фото, 1 кредит) и вертикальное видео на 8 секунд для Reels, Shorts и VK Клипов (собирается локально через Pillow и ffmpeg из пакета imageio-ffmpeg, бесплатно). Код: `bot/portfolio.py`, `bot/handlers/folio.py`, `bot/web_folio.py`.

## Команды
Для всех: `/start`, `/menu`, `/objects` — мои объекты, `/report` — фотоотчёт, `/scanner` — подключить LiDAR-сканер на iPhone, `/paysupport` — помощь
с оплатой (обязательна по правилам Telegram), `/terms` — условия, `/help`.

Для админа:
- `/stats` — пользователи, звёзды, генерации, объекты, приглашённые
- `/give <user_id> <кредиты>` — начислить кредиты (например, себе для тестов)
- `/refund <код платежа>` — вернуть звёзды и списать кредиты этой покупки (код видно в `/paysupport`)
- `/reply <user_id> <текст>` — ответить на обращение из `/paysupport`

## Где что менять
- Цены, пакеты, бонус за друга, лимиты — `bot/config.py`
- Промпты, стили дизайна — `bot/prompts.py`
- Тексты кнопок — `bot/keyboards.py`
- Экраны Mini App — `bot/webapp/index.html`, его API — `bot/web.py` и `bot/web_tools.py`

## Проверка
`python -m pytest -q` — 54 теста: калькуляторы, база, оплата и возвраты, рефералка, учёт объектов,
PDF, защита Mini App, сканы и ремонт в 3D, мебель по размерам и сквозные сценарии бота (без настоящего Telegram и kie.ai).

## Сервер
VPS с Ubuntu (Timeweb, Beget, Selectel — от 300 ₽/мес). Скопируйте проект в `/opt/stroybot`,
выполните шаги «Запуск», затем включите автозапуск: `deploy/stroybot.service` (инструкция внутри файла).
