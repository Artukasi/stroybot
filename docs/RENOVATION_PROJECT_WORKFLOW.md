# СтройСкан — единый маршрут «Проект ремонта»

Ветка ios-more, версия первой интеграции.

## Как открыть

Главный экран → «Проекты ремонта» → выбрать сохранённую комнату. Или открыть сохранённую комнату → «Проект ремонта: работы и закупки».

## Текущие возможности

1. **Замеры.** Привязка к существующей RoomResult и её измеренной площади пола, стен, окон и дверей.
2. **Планирование.** Переход к схеме каркаса ГКЛ; просмотр инженерных трасс. Для сохранения инженерных изменений используется исходный редактор комнаты.
3. **Смета.** Открытие существующей EstimateView, переход к ForemanGuideView, список типовых материалов из Estimate.rows.
4. **Закупка.** Перенос строк типовых материалов в покупки без повторных дублей (по ID исходной строки), добавление своих материалов и отметка покупки.
5. **Выполнение.** Стартовые типовые работы, добавление и удаление задач, состояния «Не начато / В работе / Готово».
6. **Отчёт.** Формирование текстового отчёта клиенту с работами и закупками; обмен через системный ShareLink.
7. **Данные.** JSON по UUID скана в Documents/StroyScan/Projects, отдельный от содержимого RoomResult. Заголовок, имя клиента, заметки и этапы сохраняются атомарно.

## Ограничения первой версии

- Проект формируется **на одну сохранённую комнату**, а не на общую квартиру; поддержка объединённого объекта со всеми помещениями — отдельная миграция.
- Импорт материалов берёт типовую смету, а не финальный заказ: фактический расход, упаковки, цены и технические решения нужно проверить.
- Не реализован полноценный BOM для конкретных конструкций ГКЛ и MEP, реальные календарные сроки/зависимости, полноценный PDF-отчёт из единого проекта.
- Экспорт общего проекта сейчас текстовый, отдельный JSON-файл проекта сохраняется в контейнере приложения. Следующее улучшение — резервное копирование всех проектов в Backup.
- Автопрокладка труб и кабелей — геометрический черновик, не проект для монтажа.
- Новая 3D-конструкция не является схемой несущей способности, пожаробезопасности или электрозащиты.

## Обязательные проверки на iPhone

Создать LiDAR-комнату → открыть проект → изменить заголовок → выбрать стадию → добавить материал и задачу → отметить покупку и выполнение → закрыть приложение → заново открыть проект → убедиться, что всё сохранено → перенести материалы из сметы дважды → убедиться, что дублей нет → ShareLink → убедиться в корректном содержимом отчёта.

CI проверяет сборку, но не фактическую работу интерфейса, точность LiDAR и устойчивость данных в условиях сбоя питания.
