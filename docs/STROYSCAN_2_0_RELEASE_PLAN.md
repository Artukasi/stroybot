# СтройСкан 2.0 — этапы модернизации и проверка релиза

Версия ветки: `ios-more`. Исходный проект iOS с минимальной версией iOS 16.

## Внедрено в текущую серию коммитов

- **Надёжность проектов:** обновление счётчика изменений при редактировании проекта, восстановление JSON проектов из ZIP, удаление связанных документов при сознательном удалении скана.
- **Новая структура:** 4 нижние вкладки «Главная», «Объекты», «Сканер», «Помощник». Старые экраны сохранены; их функции доступны через разделы и сворачиваемые дополнительные инструменты.
- **Продолжение работы:** карточка последней изменённой комнаты на главном экране.
- **Навигация по комнатам:** переход из квартиры к проекту комнаты и режиму досъёмки; новая вкладка сканера пользуется общим механизмом сохранения результатов и экспортирует объединённый USDZ на поддерживаемой iOS.
- **Проект квартиры:** свод площадей и комнат, общие задачи с состояниями, заметки, текстовый отчёт; проекты комнат остаются отдельными.
- **Формулы материалов:** общее ядро расхода для части позиций обычной сметы и закупочного калькулятора, тесты в GitHub Actions (проверить статус конкретной последней сборки).
- **Фото скрытых работ:** ручное сохранение фотодоказательств с комментариями и категорией, привязка к сканированной комнате, резервное копирование и восстановление вложений.
- **Дизайн:** обновлена графитово-янтарная палитра в общем компоненте оформления.

## Предстоящие задачи, которые НЕ реализованы до полноценного теста на устройстве

1. Реальное AR-наложение каркаса ГКЛ в процессе LiDAR-съёмки (мировые якоря, проверка устойчивости, отключение наложения).
2. Редактирование перегородок и труб касаниями непосредственно на плане, откат/повтор действий, блокировка пересечений.
3. Производитель-специфичные монтажные системы (тип профилей, толщина, крепления, нагрузки, пожарные узлы, раскрой с отходами).
4. Интеграция с официальным каталогом, ценами, складом и корзиной Петровича; без API нельзя считать заказ в магазине оформленным.
5. Общая **нормализованная** ведомость материалов и стоимость всей квартиры: сначала нужны артикулы, единицы и условия закупки по комнатам.
6. Роли мастера и прораба, назначение бригад и сроки; пока задачи ведутся на устройстве без синхронизации пользователей.
7. Полноценный PDF-отчёт общего проекта, документы по актам и контроль согласований. Сейчас общий отчёт текстовый.
8. Интеграционные и UI-тесты на настоящих устройствах, а также точность LiDAR в помещении с дверями, нишами и наклонными стенами.

## Обязательная приёмка iOS 2.0 на реальном iPhone

- Установка подписанного IPA без потери данных предыдущей версии.
- Переключение всех вкладок и восстановление состояния после сворачивания.
- Скан комнаты из вкладки «Сканер»; проверка 3D, размеров, PDF, DXF.
- Досъёмка из «Объекты»; проверка переноса инженерных отметок и архивирования несовместимых.
- Сквозная съёмка квартиры и экспорт USDZ (для iOS 17+).
- Изменение задач/закупок и ручной экспорт/восстановление ZIP в чистое приложение.
- Фото скрытых работ, удаление, экспорт и восстановление.
- Переход из «Помощник» к ИИ: сценарии с ключом, без ключа и без интернета.
- Согласованность расчётов сметы и списка Петровича; проверка реальных паспортов товаров.
- Контраст, размеры кнопок, Dynamic Type, скринридер, низкая освещённость.
- Проверка производительности на длинных списках и больших 3D-моделях.

**Важно:** GitHub Actions подтверждает только компиляцию и простые тесты формул, но не точность измерения, безопасность монтажных схем или установку конкретного IPA. Проект не должен заявлять соответствие СП/ГОСТ или возможность автоматической безопасной трассировки без отдельной инженерной проверки.
