# СтройСкан — замер комнаты лидаром iPhone

Приложение для iPhone Pro (12 Pro и новее). Apple RoomPlan строит по лидару стены, окна и двери,
приложение считает площади и отправляет их в СтройБот. В боте и в Mini App («Инструменты» → «Замер по скану»)
скан сразу превращается в расчёт материалов и смету.

## Как получить приложение бесплатно (без Mac)

### 1. Собрать на GitHub
1. Загрузите проект в свой репозиторий на GitHub.
2. Откройте вкладку **Actions** → **iOS StroyScan** → **Run workflow**. Сборка идёт на Mac-серверах GitHub, это бесплатно.
3. Когда запуск станет зелёным, откройте его и скачайте **StroyScan-ipa** внизу страницы (в архиве файл `StroyScan.ipa`).

### 2. Поставить на iPhone с компьютера на Windows
Проще всего через **Sideloadly** (sideloadly.io):
1. Установите iTunes и iCloud с сайта Apple (не из Microsoft Store), затем Sideloadly.
2. Подключите iPhone кабелем, нажмите на телефоне «Доверять этому компьютеру».
3. Перетащите `StroyScan.ipa` в Sideloadly, введите свой Apple ID и нажмите **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
5. На iOS 16 и новее включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** и перезагрузите телефон.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить тем же способом.
В Sideloadly можно включить автообновление подписи, если компьютер включён и в той же сети Wi‑Fi.
Можно пользоваться и **AltStore** (altstore.io) — он продлевает подпись сам.

## Подключение к боту
1. Напишите боту `/scanner` или откройте Mini App → «Профиль» → «Подключить iPhone».
2. Нажмите ссылку на iPhone: СтройСкан откроется и подключится сам. Или введите в приложении адрес бота и код.

## Для разработчика
- Код: `StroyScan/Sources`, проект Xcode собирается из `StroyScan/project.yml` программой XcodeGen.
- Сервер: `bot/web_scan.py` (`/scan/pair`, `/scan/rooms`), сканы хранятся в таблице `scans`.
- Минимальная iOS 16. На iOS 17+ контур пола берётся из RoomPlan, на iOS 16 — выпуклая оболочка по стенам.
