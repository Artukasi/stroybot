# Запуск бота на своём компьютере с Windows (бесплатно)

Бот работает, пока включён компьютер и открыто чёрное окно запуска. Хостинг не нужен:
бесплатный https-адрес для Mini App и iPhone-сканера даёт Cloudflare.

## Что понадобится

1. **Токен бота.** В Telegram откройте @BotFather → `/newbot` → имя (например «СтройБот») → адрес,
   который кончается на `bot`. BotFather пришлёт токен вида `1234567890:AAH...`.
2. **Ключ kie.ai.** Зайдите на https://kie.ai, войдите через Google, откройте https://kie.ai/api-key,
   создайте ключ. Для работы ИИ на балансе kie.ai нужны кредиты (это единственное платное).

Токен и ключ **не отправляйте в чат**: вставьте их только в окно запуска, они сохранятся в файл `.env`
на вашем компьютере.

## Первый запуск

1. На странице https://github.com/Artukasi/stroybot нажмите зелёную кнопку **Code → Download ZIP**,
   распакуйте архив (например, в «Документы»).
2. Откройте распакованную папку и дважды щёлкните **start-bot.bat**.
   Если Windows покажет синее окно «Windows защитила компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Окно само поставит Python (если его нет) и библиотеки, потом спросит токен и ключ.
   Вставить текст в окно: правый щелчок мыши.
4. Когда окно попросит, откройте своего бота в Telegram и нажмите «Старт»: так скрипт узнает ваш ID
   и сделает вас администратором.
5. Скрипт проверит ключи (строки `[ok]`) и запустит бота. Готово: пишите боту, внизу появится кнопка «Приложение».

## Чтобы бот работал всегда (рекомендуется)

После первого запуска дважды щёлкните **autostart-on.bat**. Бот уйдёт в фон: чёрное окно держать не нужно,
он сам запускается при входе в Windows, сам перезапускается, если упал, и сам берёт новый адрес Cloudflare,
если старый перестал отвечать. Журнал — `windows\logs\bot.log`. Выключить автозапуск — **autostart-off.bat**.

Компьютер при этом должен быть включён и с интернетом. Если нужен бот 24/7 без своего компьютера — нужен
сервер (VPS, от 200–300 ₽ в месяц), инструкция в `deploy/`.

## Каждый следующий раз

Дважды щёлкните **start-bot.bat**. Ничего вводить не нужно.

- Адрес от Cloudflare меняется при каждом запуске, бот сам обновляет кнопку «Приложение».
- iPhone-сканер после перезапуска нужно подключить заново: команда `/scanner` в боте.
- Чтобы бот не засыпал: Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда».
- Поменять ключи: откройте файл `.env` блокнотом.
